# 🎓🏛️ UNIVERSITY MANAGEMENT SYSTEM

### 💻 SQL Database Management Project \| MySQL

------------------------------------------------------------------------

## 🌟📌 Project Overview

Welcome to the **University Management System**! 🎓

The University Management System is a SQL-based database project
designed to manage university information efficiently and
systematically.

This project helps maintain and organize records of students,
departments, courses, instructors, and enrollments. It demonstrates how
SQL can be used to store, retrieve, manage, and analyze university data.

## 🎯🚀 Project Objectives

-   🎓 Manage student information.
-   🏢 Maintain department records.
-   📚 Organize university courses.
-   👨‍🏫 Manage instructor information.
-   📝 Track student course enrollments.
-   🔗 Establish relationships between database tables.
-   📊 Retrieve useful information through SQL queries.
-   💡 Apply SQL concepts to real-world database management.

## 🗄️💾 Database Information

**Database Name:** University Management System

**Total Tables:** 5

## 📚📋 Database Tables

### 1️⃣ 🏢 Department Table

Stores information about different university departments.

**Columns:** - 🆔 Department ID - 🏷️ Department Name

### 2️⃣ 🎓 Student Table

Stores personal and academic information about students.

**Columns:** - 🆔 Student ID - 👤 First Name - 👤 Last Name - 📧 Email -
🎂 Birth Date - 📅 Enrollment Date

### 3️⃣ 📖 Courses Table

Maintains information about courses offered by different departments.

**Columns:** - 🆔 Course ID - 📚 Course Name - 🏢 Department ID - ⭐
Credits

### 4️⃣ 👨‍🏫 Instructors Table

Stores information about university instructors.

**Columns:** - 🆔 Instructor ID - 👤 First Name - 👤 Last Name - 📧
Email - 🏢 Department ID

### 5️⃣ 📝 Enrollments Table

Maintains student enrollment records for different courses.

**Columns:** - 🆔 Enrollment ID - 🎓 Student ID - 📚 Course ID - 📅
Enrollment Date - 🏆 Grade

## 🔗📊 Database Relationships

The project uses Primary Keys and Foreign Keys to establish
relationships between tables.

-   🏢 Department → Courses
-   🏢 Department → Instructors
-   🎓 Student → Enrollments
-   📚 Courses → Enrollments

These relationships help maintain data consistency and integrity.

## 📊🔍 Project Queries and Operations

The project performs the following SQL operations:

1.  🎓 Retrieve students enrolled after 2022.
2.  📚 Find courses offered by the Mathematics department.
3.  📊 Count students enrolled in each course.
4.  🔗 Find students enrolled in both selected courses.
5.  🔍 Find students enrolled in either selected course.
6.  📈 Calculate the average credits of all courses.
7.  🏢 Count students enrolled in each department.
8.  🔄 Retrieve student and course details using INNER JOIN.
9.  📋 Retrieve all students using LEFT JOIN.
10. 🔎 Find students enrolled in courses having more than one student.
11. 📅 Extract the enrollment year.
12. 👨‍🏫 Combine instructor first and last names.
13. 📊 Calculate the running total of student enrollments.
14. 🏆 Classify students as Senior or Junior based on enrollment date.
